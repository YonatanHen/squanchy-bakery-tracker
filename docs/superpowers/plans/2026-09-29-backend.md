# Fridge Tracker Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Flask + PostgreSQL backend that stores validated logger readings, registers branches/fridges/loggers, detects alerts deterministically, and answers the inspector with filtered queries.

**Architecture:** Flask app factory with one versioned blueprint (`/api/v1`). SQLAlchemy models map the ERD. Uploads go through parser (Strategy + Factory) → Pydantic validation with a DB registry as context → repository (one transaction) → detection service (pure rule functions). JWT guards every route except health and login.

**Tech Stack:** Python 3.14, Flask 3.1, Flask-SQLAlchemy 3.1 (SQLAlchemy 2), psycopg 3, Pydantic 2, PyJWT 2, openpyxl 3.1, pytest 8, PostgreSQL 16 (Docker Compose).

**Spec:** `docs/superpowers/specs/2026-09-29-fridge-tracker-design.md`

## Global Constraints

- All routes under `/api/v1/`. Every route except `GET /api/v1/health` and `POST /api/v1/auth/login` requires `Authorization: Bearer <JWT>`; missing or invalid token → 401.
- Pydantic v2 for every request body, response body, query string and parsed file row (CLAUDE.md rule 7). No other validation library.
- TDD: failing test first, run it, see it fail for the expected reason, then minimal code (CLAUDE.md rule 5). Use the `superpowers:test-driven-development` skill for each task.
- Tests trace to a requirement or a known data problem; no unrelated tests (CLAUDE.md rule 4).
- One commit per task step group; commit messages are plain sentences, no Claude attribution (CLAUDE.md rule 3).
- Code comments: 1-2 lines max.
- Three layers: `app/models/` (data), `app/services/` (business logic), `app/api/` (thin routes: validate input with Pydantic, call a service, format the response). Route snippets below that query or write the DB move that code into a service function. Path mapping for later tasks: `app/tokens.py` → `app/services/tokens.py`, `app/archive.py` → `app/services/archive.py`, `app/ingest/` → `app/services/ingest/`, `app/detection/` → `app/services/detection/`, `app/units.py` → `app/services/units.py`; branch/fridge, thresholds, readings and alerts logic → `app/services/{branches,thresholds,readings,alerts}.py`.
- One schema module per entity under `app/schemas/`: `branch.py` (BranchOut, BranchPatch), `fridge.py` (FridgeOut, FridgePatch, DeleteImpact), `thresholds.py`, `reading.py` (ReadingFilters, ReadingOut, ReadingPatch), `alert.py` (AlertFilters, AlertOut); shared field types (`Name`, `BuildingNumber`, `LoggerId`) in `app/schemas/types.py`. Where a snippet says `app/schemas/branches.py` or `app/schemas/readings.py`, use the matching entity module.
- Thresholds are named threshold settings shared by many fridges (Task 17 as built): read them as `fridge.threshold_settings`, not `fridge.thresholds`. Detection snippets (Tasks 18-21) that use `fridge.thresholds` use `fridge.threshold_settings`; tests that change one fridge's limits create new threshold settings and attach that fridge to it.
- One model per module under `backend/app/models/` (`from app.models import X` still works). Where a later task says "modify `backend/app/models.py`", add a new module (e.g. `app/models/user.py`) and export it from `app/models/__init__.py`.
- Deletes never lose history: deleting a branch, fridge, logger or reading moves its readings and alerts to `reader_archive` / `alert_archive` (Task 4). Edits update in place; the UI asks "Are you sure?" before saving.
- Server logs follow CLAUDE.md rule 12: INFO for process results with counts, WARNING for rejected input without values, ERROR for failures; never passwords, tokens or file contents.
- Every function, including tests and fixtures, gets a docstring: one line saying what it does, then `Args:` / `Returns:` only when needed (CLAUDE.md rule 11). Snippets below may omit them; add them while implementing.
- Each branch section below = one `dev/` branch = one PR to `master`. After `gh pr create`, give the user the link and stop until they say to continue (CLAUDE.md rule 2). Never merge.
- New decisions, doubts and rejected AI output during execution are logged through the `logging-decisions` skill.
- Default thresholds: growth 0.1 / 1.0, deviation 1.5 / 3.0 (°C), gap > 15 / ≥ 120 minutes.
- Accepted date formats: `YYYY-MM-DD HH:MM`, `DD/MM/YYYY HH:MM`, Excel datetime cells.
- Logger id format: `TL-` + 4 digits.
- Commands run from `backend/`. Python: `.venv/Scripts/python`. DB must be up: `docker compose up -d --wait` (repo root).

## Review Focus

- A typo in a fridge name for a known logger ("Diary") is treated as a display rename; Summer must see it in the upload result → pinned in Task 14 (`renamed_fridges` lists it).
- The same logger and time twice in one file with different temperatures → first row kept, the second counted as a duplicate → pinned in Task 14.
- An uploaded sheet with only the header row → 201 with `inserted: 0`, not a crash → pinned in Task 14.
- Thresholds are °C but a Fahrenheit fridge reports °F: a 2°F rise (1.1°C) must not trigger a 1.5°C deviation → pinned in Task 21.
- A reading moved to a time that already exists for its logger (PATCH) → 409, not a 500 → pinned in Task 23.
- A typo in a branch name ("Rishon LeZoin") must come back as "did you mean", never be created silently; an unknown logger is listed without a guess → pinned in Task 14b.
- Summer confirms a new branch, but another row in the file is still invalid → nothing is saved, not even the branch → pinned in Task 14c.

```python
import enum
from datetime import datetime

from sqlalchemy import DateTime, Enum, ForeignKey, Index, String, func
from sqlalchemy.orm import Mapped, mapped_column, relationship

from app.db import db


class Metric(str, enum.Enum):
    C = "C"
    F = "F"


metric_enum = Enum(Metric, name="metric")


class Branch(db.Model):
    __tablename__ = "branch"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(100))
    city: Mapped[str | None] = mapped_column(String(100))
    street: Mapped[str | None] = mapped_column(String(200))
    building_number: Mapped[str | None] = mapped_column(String(20))

    fridges: Mapped[list["Fridge"]] = relationship(
        back_populates="branch", cascade="all, delete-orphan", passive_deletes=True
    )


class ThresholdSettings(db.Model):
    __tablename__ = "threshold_settings"

    id: Mapped[int] = mapped_column(primary_key=True)
    fridge_id: Mapped[int] = mapped_column(ForeignKey("fridge.id", ondelete="CASCADE"), unique=True)
    growth_non_urgent: Mapped[float] = mapped_column(default=0.1)
    growth_urgent: Mapped[float] = mapped_column(default=1.0)
    deviation_non_urgent: Mapped[float] = mapped_column(default=1.5)
    deviation_urgent: Mapped[float] = mapped_column(default=3.0)
    gap_non_urgent_minutes: Mapped[int] = mapped_column(default=15)
    gap_urgent_minutes: Mapped[int] = mapped_column(default=120)

    fridge: Mapped["Fridge"] = relationship(back_populates="thresholds")


class Fridge(db.Model):
    __tablename__ = "fridge"

    id: Mapped[int] = mapped_column(primary_key=True)
    branch_id: Mapped[int] = mapped_column(ForeignKey("branch.id", ondelete="CASCADE"))
    name: Mapped[str] = mapped_column(String(100))
    metric: Mapped[Metric] = mapped_column(metric_enum, default=Metric.C)
    avg_temp: Mapped[float | None] = mapped_column()
    last_measured: Mapped[datetime | None] = mapped_column(DateTime)

    branch: Mapped[Branch] = relationship(back_populates="fridges")
    thresholds: Mapped[ThresholdSettings] = relationship(
        back_populates="fridge", cascade="all, delete-orphan", passive_deletes=True
    )

    def __init__(self, **kwargs):
        kwargs.setdefault("thresholds", ThresholdSettings())
        super().__init__(**kwargs)


Index("uq_branch_name_lower", func.lower(Branch.name), unique=True)
Index("uq_fridge_branch_name_lower", Fridge.branch_id, func.lower(Fridge.name), unique=True)
```

```python
from app.models import Branch, Fridge, Logger, Metric


def add_fridge(session, branch="Jerusalem", fridge="Dairy", logger="TL-0512", metric=Metric.C) -> Fridge:
    """Create a fridge (and its branch if missing) with one logger."""
    existing = session.scalar(select(Branch).where(func.lower(Branch.name) == branch.lower()))
    new_fridge = Fridge(branch=existing or Branch(name=branch, city=branch), name=fridge, metric=metric)
    if logger:
        new_fridge.logger = Logger(id=logger)
    session.add(new_fridge)
    session.commit()
    return new_fridge
```

```python
from datetime import datetime, timedelta, timezone

import jwt
from flask import current_app


def create_token(username: str, expires_minutes: int | None = None) -> str:
    minutes = current_app.config["JWT_EXPIRES_MINUTES"] if expires_minutes is None else expires_minutes
    payload = {"sub": username, "exp": datetime.now(timezone.utc) + timedelta(minutes=minutes)}
    return jwt.encode(payload, current_app.config["JWT_SECRET"], algorithm="HS256")


def decode_token(token: str) -> str:
    payload = jwt.decode(token, current_app.config["JWT_SECRET"], algorithms=["HS256"])
    return payload["sub"]
```

```python
from typing import Any

from pydantic import BaseModel, ValidationError


class FieldError(BaseModel):
    row: int | None = None
    field: str
    value: Any = None
    message: str


def _jsonable(value: Any) -> Any:
    return value if value is None or isinstance(value, (str, int, float, bool)) else str(value)


def field_errors(exc: ValidationError, row: int | None = None) -> list[FieldError]:
    return [
        FieldError(
            row=row,
            field=".".join(str(part) for part in e["loc"]) or "body",
            value=None if e["type"] == "missing" else _jsonable(e.get("input")),
            message=e["msg"].removeprefix("Value error, "),
        )
        for e in exc.errors()
    ]
```

```python
DATE_FORMATS = ("%Y-%m-%d %H:%M", "%d/%m/%Y %H:%M")


def parse_time(value: Any) -> datetime:
    if isinstance(value, datetime):
        return value
    text = collapse_spaces(value)
    for fmt in DATE_FORMATS:
        try:
            return datetime.strptime(text, fmt)
        except ValueError:
            continue
    raise ValueError(f"Unrecognized date '{text}'. Use YYYY-MM-DD HH:MM or DD/MM/YYYY HH:MM")


def parse_temp(value: Any) -> float | None:
    """Return the temperature, or None for an ERR reading."""
    if isinstance(value, (int, float)) and not isinstance(value, bool):
        return float(value)
    text = collapse_spaces(value)
    if text.upper() == "ERR":
        return None
    try:
        return float(text)
    except ValueError:
        raise ValueError("Temperature must be a number or ERR") from None
```

```python
from dataclasses import dataclass

from sqlalchemy import select
from sqlalchemy.orm import selectinload

from app.models import Branch, Fridge, Metric


@dataclass(frozen=True)
class LoggerInfo:
    fridge_id: int
    branch: str
    fridge: str
    metric: Metric


@dataclass(frozen=True)
class Registry:
    branches: dict[str, str]
    loggers: dict[str, LoggerInfo]
    fridges: dict[tuple[str, str], int]


def load_registry(session) -> Registry:
    """Snapshot of registered branches, fridges and loggers used to validate uploads."""
    branches = {b.name.lower(): b.name for b in session.scalars(select(Branch))}
    loggers: dict[str, LoggerInfo] = {}
    fridges: dict[tuple[str, str], int] = {}
    query = select(Fridge).options(selectinload(Fridge.branch), selectinload(Fridge.logger))
    for fridge in session.scalars(query):
        fridges[(fridge.branch.name.lower(), fridge.name.lower())] = fridge.id
        if fridge.logger:
            loggers[fridge.logger.id] = LoggerInfo(fridge.id, fridge.branch.name, fridge.name, fridge.metric)
    return Registry(branches, loggers, fridges)
```

```python
import re
from datetime import datetime
from typing import Any

from pydantic import BaseModel, ValidationInfo, field_validator, model_validator
from pydantic_core import PydanticCustomError

from app.ingest.normalizer import LOGGER_PATTERN, collapse_spaces, parse_temp, parse_time
from app.ingest.registry import Registry
from app.models import Status


def _registry(info: ValidationInfo) -> Registry:
    return info.context["registry"]


class ReadingIn(BaseModel):
    logger: str
    branch: str
    fridge: str
    time: datetime
    temp: float | None
    status: Status = Status.OK

    @field_validator("logger", mode="before")
    @classmethod
    def known_logger(cls, value: Any, info: ValidationInfo) -> str:
        logger_id = collapse_spaces(value).upper()
        if not re.fullmatch(LOGGER_PATTERN, logger_id):
            raise ValueError("Logger id must match TL-NNNN")
        if logger_id not in _registry(info).loggers:
            raise PydanticCustomError("unknown_logger", "Unknown logger")
        return logger_id

    @field_validator("branch", mode="before")
    @classmethod
    def known_branch(cls, value: Any, info: ValidationInfo) -> str:
        registry = _registry(info)
        name = registry.branches.get(collapse_spaces(value).lower())
        if name is None:
            raise PydanticCustomError("unknown_branch", "Unknown branch name")
        logger_id = info.data.get("logger")
        if logger_id and registry.loggers[logger_id].branch != name:
            raise ValueError(f"Logger {logger_id} belongs to branch {registry.loggers[logger_id].branch}")
        return name

    @field_validator("fridge", mode="before")
    @classmethod
    def fridge_of_logger(cls, value: Any, info: ValidationInfo) -> str:
        name = collapse_spaces(value)
        if not name:
            raise ValueError("Fridge name is required")
        registry, logger_id, branch = _registry(info), info.data.get("logger"), info.data.get("branch")
        if not (logger_id and branch):
            return name
        own = registry.loggers[logger_id]
        if name.lower() == own.fridge.lower():
            return own.fridge
        other = registry.fridges.get((branch.lower(), name.lower()))
        if other is not None and other != own.fridge_id:
            raise ValueError(f"Fridge '{name}' uses another logger")
        return name  # same logger, new name: the fridge changed its display

    @field_validator("time", mode="before")
    @classmethod
    def normalized_time(cls, value: Any) -> datetime:
        return parse_time(value)

    @field_validator("temp", mode="before")
    @classmethod
    def normalized_temp(cls, value: Any) -> float | None:
        return parse_temp(value)

    @model_validator(mode="after")
    def err_status(self):
        self.status = Status.ERR if self.temp is None else Status.OK
        return self
```

```python
from typing import Any, BinaryIO, Protocol

REQUIRED_COLUMNS = ("logger", "branch", "fridge", "time", "temp")


@dataclass(frozen=True)
class RawRow:
    row: int
    values: dict[str, Any]


class ReadingParser(Protocol):
    def can_parse(self, filename: str, head: bytes) -> bool: ...

    def parse(self, stream: BinaryIO) -> list[RawRow]: ...


class UnsupportedFormat(Exception):
    pass


class MissingColumns(Exception):
    def __init__(self, missing: list[str]):
        super().__init__(f"Missing columns: {', '.join(missing)}")
```

```python
from typing import BinaryIO

from openpyxl import load_workbook

from app.ingest.normalizer import collapse_spaces
from app.ingest.parsers.base import REQUIRED_COLUMNS, MissingColumns, RawRow

XLSX_MAGIC = b"PK\x03\x04"  # .xlsx is a ZIP archive


class ExcelParser:
    def can_parse(self, filename: str, head: bytes) -> bool:
        return filename.lower().endswith(".xlsx") and head.startswith(XLSX_MAGIC)

    def parse(self, stream: BinaryIO) -> list[RawRow]:
        workbook = load_workbook(stream, read_only=True, data_only=True)
        rows = workbook.active.iter_rows(values_only=True)
        header = next(rows, None) or ()
        columns = {collapse_spaces(h).lower(): i for i, h in enumerate(header) if h is not None}
        missing = [c for c in REQUIRED_COLUMNS if c not in columns]
        if missing:
            workbook.close()
            raise MissingColumns(missing)
        result = []
        for number, values in enumerate(rows, start=2):
            if all(v is None for v in values):
                continue
            result.append(RawRow(number, {c: values[columns[c]] if columns[c] < len(values) else None for c in REQUIRED_COLUMNS}))
        workbook.close()
        return result
```

```python
from sqlalchemy import select

from app.ingest.registry import Registry
from app.ingest.schemas import ReadingIn, SaveResult
from app.models import Fridge, Reader, Status


class ReadingRepository:
    """The single write path for readings."""

    def __init__(self, session, registry: Registry):
        self.session = session
        self.registry = registry
        self.new_readers: list[Reader] = []

    def save_many(self, readings: list[ReadingIn]) -> SaveResult:
        result = SaveResult()
        seen = self._existing_keys(readings)
        for reading in readings:
            key = (reading.logger, reading.time)
            if key in seen:
                result.duplicates += 1
                continue
            seen.add(key)
            reader = Reader(
                logger_id=reading.logger,
                time=reading.time,
                temp=reading.temp,
                metric=self.registry.loggers[reading.logger].metric,
                status=reading.status,
            )
            self.session.add(reader)
            self.new_readers.append(reader)
            result.inserted += 1
            result.err_rows += reading.status is Status.ERR
        result.renamed_fridges = self._apply_renames(readings)
        self.session.flush()
        return result

    def _existing_keys(self, readings: list[ReadingIn]) -> set:
        loggers = {r.logger for r in readings}
        rows = self.session.execute(select(Reader.logger_id, Reader.time).where(Reader.logger_id.in_(loggers)))
        return {(logger_id, time) for logger_id, time in rows}

    def _apply_renames(self, readings: list[ReadingIn]) -> list[str]:
        latest: dict[str, ReadingIn] = {}
        for reading in readings:
            if reading.logger not in latest or reading.time > latest[reading.logger].time:
                latest[reading.logger] = reading
        renamed = []
        for logger_id, reading in latest.items():
            info = self.registry.loggers[logger_id]
            fridge = self.session.get(Fridge, info.fridge_id)
            newer = fridge.last_measured is None or reading.time >= fridge.last_measured
            if reading.fridge != fridge.name and newer:
                renamed.append(f"{info.branch}: {fridge.name} -> {reading.fridge}")
                fridge.name = reading.fridge
        return renamed
```

```python
from difflib import get_close_matches

from pydantic import BaseModel

from app.ingest.normalizer import collapse_spaces
from app.ingest.registry import Registry


class UnknownBranch(BaseModel):
    name: str
    suggestion: str | None = None


class UnknownLogger(BaseModel):
    """No suggestion: IDs like TL-0512 and TL-0513 look alike but are different loggers."""
    logger: str
    branch: str
    fridge: str


class UnknownEntries(BaseModel):
    branches: list[UnknownBranch] = []
    loggers: list[UnknownLogger] = []


def _closest(value: str, candidates) -> str | None:
    match = get_close_matches(value, list(candidates), n=1, cutoff=0.8)
    return match[0] if match else None


def find_unknown(failed: list[tuple[dict, set[str]]], registry: Registry) -> UnknownEntries:
    """Unregistered branches and loggers of the failed rows, each listed once."""
    result, seen = UnknownEntries(), set()
    for values, error_types in failed:
        branch = collapse_spaces(values.get("branch"))
        if "unknown_branch" in error_types and branch.lower() not in seen:
            seen.add(branch.lower())
            hit = _closest(branch.lower(), registry.branches)
            result.branches.append(UnknownBranch(name=branch, suggestion=registry.branches.get(hit)))
        logger = collapse_spaces(values.get("logger")).upper()
        if "unknown_logger" in error_types and logger not in seen:
            seen.add(logger)
            result.loggers.append(UnknownLogger(
                logger=logger,
                branch=registry.branches.get(branch.lower(), branch),
                fridge=collapse_spaces(values.get("fridge")),
            ))
    return result
```

```python
class Registration(BaseModel):
    branches: list[NewBranch] = []
    fridges: list[NewFridge] = []

    @model_validator(mode="after")
    def fridge_branches_exist(self, info: ValidationInfo):
        known = info.context["branches"] | {b.name.lower() for b in self.branches}
        for new in self.fridges:
            if new.branch.lower() not in known:
                raise ValueError(f"Branch '{new.branch}' does not exist. Add it to branches")
        return self


def parse_registration(session, raw: str | dict | None) -> Registration | None:
    if not raw:
        return None
    context = {"branches": {name.lower() for name in session.scalars(select(Branch.name))}}
    if isinstance(raw, str):
        return Registration.model_validate_json(raw, context=context)
    return Registration.model_validate(raw, context=context)


def apply_registration(session, registration: Registration) -> None:
    """Add the confirmed entities to the session; the caller commits or rolls back."""
    branches = {b.name.lower(): b for b in session.scalars(select(Branch))}
    for new in registration.branches:
        branches[new.name.lower()] = Branch(**new.model_dump())
        session.add(branches[new.name.lower()])
    for new in registration.fridges:
        branch = branches[new.branch.lower()]
        session.add(Fridge(branch=branch, name=new.fridge, metric=new.metric, logger=Logger(id=new.logger_id)))
    session.flush()
```

```python
from dataclasses import dataclass
from datetime import datetime

from app.models import AlertLevel


@dataclass(frozen=True)
class Point:
    id: int
    time: datetime
    temp_c: float | None  # None for an ERR reading
    is_new: bool


@dataclass(frozen=True)
class Thresholds:
    growth_non_urgent: float
    growth_urgent: float
    deviation_non_urgent: float
    deviation_urgent: float
    gap_non_urgent_minutes: int
    gap_urgent_minutes: int


@dataclass(frozen=True)
class Finding:
    point_id: int
    level: AlertLevel
    description: str


def _by_time(points: list[Point]) -> list[Point]:
    return sorted(points, key=lambda p: (p.time, p.id))


def find_gaps(points: list[Point], t: Thresholds) -> list[Finding]:
    findings = []
    ordered = _by_time(points)
    for previous, current in zip(ordered, ordered[1:]):
        if not current.is_new:
            continue
        minutes = (current.time - previous.time).total_seconds() / 60
        if minutes >= t.gap_urgent_minutes:
            level = AlertLevel.URGENT
        elif minutes > t.gap_non_urgent_minutes:
            level = AlertLevel.NON_URGENT
        else:
            continue
        duration = f"{int(minutes // 60)}h {int(minutes % 60)}m"
        findings.append(Finding(current.id, level, f"No reading for {duration} before this reading"))
    return findings
```

```python
WINDOW = 4


def _level(value: float, non_urgent: float, urgent: float) -> AlertLevel | None:
    if value >= urgent:
        return AlertLevel.URGENT
    if value >= non_urgent:
        return AlertLevel.NON_URGENT
    return None


def find_growth(points: list[Point], t: Thresholds) -> list[Finding]:
    findings = []
    ok = [p for p in _by_time(points) if p.temp_c is not None]
    for end in range(WINDOW - 1, len(ok)):
        window = ok[end - WINDOW + 1 : end + 1]
        current = window[-1]
        if not current.is_new:
            continue
        if any(b.temp_c < a.temp_c for a, b in zip(window, window[1:])):
            continue
        total = round(current.temp_c - window[0].temp_c, 2)
        level = _level(total, t.growth_non_urgent, t.growth_urgent)
        if level:
            findings.append(Finding(current.id, level, f"Temperature rose {total:.1f}°C over the last {WINDOW} readings"))
    return findings
```

```python
def find_deviations(points: list[Point], t: Thresholds) -> tuple[list[Finding], float | None]:
    """Compare each reading to the running average; spikes are alerted but not averaged."""
    findings = []
    ok = [p for p in _by_time(points) if p.temp_c is not None]
    total, count = 0.0, 0
    for index, point in enumerate(ok):
        if count == 0:
            total, count = point.temp_c, 1
            continue
        average = total / count
        deviation = round(point.temp_c - average, 2)
        if abs(deviation) < t.deviation_non_urgent:
            total, count = total + point.temp_c, count + 1
            continue
        following = ok[index + 1] if index + 1 < len(ok) else None
        if following is not None and abs(following.temp_c - average) < t.deviation_non_urgent:
            if point.is_new:
                findings.append(Finding(point.id, AlertLevel.NON_URGENT,
                                        f"Spike: {point.temp_c:.1f}°C against an average of {average:.1f}°C"))
            continue
        if point.is_new:
            level = AlertLevel.URGENT if abs(deviation) >= t.deviation_urgent else AlertLevel.NON_URGENT
            direction = "above" if deviation > 0 else "below"
            findings.append(Finding(point.id, level, f"{point.temp_c:.1f}°C is {abs(deviation):.1f}°C {direction} "
                                                     f"the fridge average of {average:.1f}°C"))
        total, count = total + point.temp_c, count + 1
    return findings, (total / count if count else None)
```

```python
from app.units import from_celsius, to_celsius


def _points(session, fridge_id: int, new_ids: set[int]) -> list[Point]:
    readers = session.scalars(select(Reader).join(Logger).where(Logger.fridge_id == fridge_id))
    return [
        Point(r.id, r.time, None if r.temp is None else to_celsius(r.temp, r.metric), r.id in new_ids)

def _thresholds(fridge: Fridge) -> Thresholds:

def _store_stats(fridge: Fridge, points: list[Point], average_c: float | None) -> None:
    fridge.avg_temp = None if average_c is None else round(from_celsius(average_c, fridge.metric), 2)
    fridge.last_measured = max((p.time for p in points), default=None)


def detect(session, fridge_ids: set[int], new_reader_ids: set[int]) -> int:
    added = 0
    for fridge_id in fridge_ids:
        fridge = session.get(Fridge, fridge_id)
        points = _points(session, fridge_id, new_reader_ids)
        t = _thresholds(fridge)
        deviations, average_c = find_deviations(points, t)
        for finding in find_gaps(points, t) + find_growth(points, t) + deviations:
            session.add(Alert(reader_id=finding.point_id, level=finding.level, description=finding.description))
            added += 1
        _store_stats(fridge, points, average_c)
    return added


def refresh_fridge_stats(session, fridge: Fridge) -> None:
    points = _points(session, fridge.id, set())
    _store_stats(fridge, points, find_deviations(points, _thresholds(fridge))[1])
```
